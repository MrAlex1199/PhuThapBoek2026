# 🏍️ ทริป 2 ล้อ 4 ล้อ บุกภูทับเบิก 2026 🚗💨

เว็บแอปพลิเคชันสำหรับวางแผนการเดินทาง ตารางเวลา จุดแวะพัก และข้อมูลสำคัญสำหรับทริปภูทับเบิก 2026

## 🌟 ฟีเจอร์หลัก (Features)
- 📅 **ตารางการเดินทางแบบละเอียด (Timeline / Itinerary):** จุดพักรถ ปั๊มน้ำมัน แหล่งท่องเที่ยว และที่พัก
- 👥 **รายชื่อและขบวนเดินทาง (Travel Squad):** แยกกลุ่มรถ 2 ล้อ และ 4 ล้อ
- ⛽ **จุดเติมพลัง & ปั๊มน้ำมัน (Fuel & Rest Stops):** พิกัด GPS ระยะทาง และจุดชาร์จ EV
- 🎒 **รายการเตรียมตัว (Checklist & Essentials):** สภาพอากาศ การเตรียมรถ อุปกรณ์จำเป็น
- 📱 **Mobile-First Responsive Design:** รองรับการเปิดดูบนสมาร์ทโฟน สะดวกระหว่างเดินทาง

## 🚀 การเปิดใช้งาน (Usage)
สามารถเปิดไฟล์ `index.html` บนเบราว์เซอร์ได้ทันที หรือดูผ่าน GitHub Pages
