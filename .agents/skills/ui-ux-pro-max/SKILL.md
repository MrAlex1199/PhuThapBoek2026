# UI/UX Pro Max Design Guidelines

This skill enforces world-class, premium UI/UX standards for travel, convoy, and interactive web applications.

## 1. Visual Aesthetics & Polish
- **Color Palettes**: Curated high-contrast palettes (e.g. Emerald/Mountain Mist `#059669`, Skyway Blue `#0284c7`, Deep Slate `#0f172a`, Warm Amber `#d97706`).
- **Glassmorphism & Depth**: Multi-layered shadows (`box-shadow`), backdrop filters (`backdrop-blur-md`), frosted glass borders (`border border-white/20`).
- **Hero Impact**: Immersive photo hero banner with clean gradient overlays, responsive typography, and clear action pills.

## 2. Media & Photography Integration
- **Aspect Ratios**: Consistent 16:9 or 4:3 ratios for landscape travel photos with subtle rounded corners (`rounded-2xl`).
- **Interactive Lightbox / Zoom**: Ability to tap or click photos to view full size with captions.
- **Lazy Loading & Performance**: Fast-loading responsive images with fallback placeholders and skeleton states.

## 3. Mobile Ergonomics & Micro-Interactions
- **Thumb Zone Design**: Primary interactive targets (checkpoints, call buttons, navigation links) sized at min 44x44px.
- **Sticky Actions**: Sleek floating bottom action bar that doesn't obstruct content.
- **Tactile Feedback**: Active press scale transitions (`active:scale-95`), smooth hover states, and clear progress indicators.

## 4. Convoy & Timeline UX
- **Distinct Vehicle Badges**: Clear visual differentiation for each vehicle type (Year, Model, Role, Driver).
- **Milestone Progress**: Clear step-by-step progress tracking with time stamps, distance markers, and status toggles.
